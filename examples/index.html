How it works

Three steps

From staged changes to committed code in seconds

01
Stage your changes
Run git add . as usual. ai-git-commit reads the staged diff automatically.
02
Run aic
The CLI reads your diff, sends it to your chosen AI provider, and generates a conventional commit message.
03
Confirm or edit
Review the message, edit if needed, or regenerate. Press Enter to commit. Done.
04
Committed
The commit is made with the AI-generated message. Your git history stays clean and consistent.

Get Started

Install & configure

Up and running in 60 seconds

Install 
# Install globally
npm install -g ai-git-commit

# Or use without installing
npx ai-git-commit
Setup 
# Interactive setup wizard
aic setup

# Or set env variable
export OPENAI_API_KEY=sk-...

# Then generate a commit
git add .
aic
Usage 
# Generate + confirm + commit
aic

# Preview only — no commit
aic --dry-run

# Auto-commit no prompt
aic --yes

# Use specific provider
aic --provider ollama
aic --provider anthropic

# View config
aic config
